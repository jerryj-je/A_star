# A_star
A-star based program for UR5e robotic arm manupulation
# UR5e Robot Pathfinding and Control via A* Algorithm

## Overview

This Python script is designed to plan a collision-free path for the UR5e robot in a 3D workspace using the **A*** algorithm. It also provides the functionality to visualize the planned path and obstacles in 3D, as well as control the robot's movement using the RTDE control interface.

## 1. **Collision Checking**

- The `is_collision_free(start, end, obstacles)` function checks if a straight path from the `start` to the `end` is free from obstacles. Further improvements can be made here by implementing a collision shape detection algorithm.

## 2. **A* Pathfinding Algorithm**

- The workspace is discretized into a grid using a `resolution` parameter, and obstacles are represented as spheres with a center and radius.
- The algorithm calculates the shortest path from a start point to a goal point while avoiding collisions with obstacles.
- It uses both **Manhattan distance** and **Euclidean distance** as heuristics to estimate the cost of reaching the goal.

## 3. **Smoothing the Path**

- The `smooth_path(path, obstacles)` function smooths the path by removing unnecessary intermediate points that would cause the robot to unnecessarily navigate around obstacles.

- The `optimize_path(path, obstacles, iterations, alpha)` function further optimizes the path by reducing sharp turns while avoiding obstacles.

## 4. **RTDE Control Interface**

- The script initializes the RTDE control interface to interact with the UR5e robot and send movement commands.
- The robot's movements are controlled based on the optimized path generated by the A* algorithm.
